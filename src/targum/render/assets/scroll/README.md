# the scroll

One photograph, for the `/parasha` hero. §12 of `design.md` records why a ritual object
is allowed on a content surface at all, and the conditions it is allowed under.

| file | what | source | licence |
|---|---|---|---|
| `columns.jpg` | Columns of a Torah scroll, close | [Closeup of Torah Scroll](https://commons.wikimedia.org/wiki/File:Closeup_of_Torah_Scroll.jpg) by Jacob Gucker, Wikimedia Commons | **CC0** |

CC0 asks for nothing, and the page credits it anyway — the same rule the recordings
follow, and for the same reason: a credit that lives only in a repository is a credit
nobody reading the page ever sees.

It is cropped to 2:1 and saved at 1000 px because that is the widest the panel is ever
drawn and anything past it is bytes on every visit for pixels nobody sees. It is inlined
into the page as a `data:` URI, like the weekly's front pages, so the landing page still
fetches nothing.

**It is a stand-in and should be replaced.** It is somebody else's scroll, chosen off
Commons for being free and roughly the right shape rather than for its crop, and at the
size the hero draws it the picture is doing real work. A commissioned photograph, or one
chosen deliberately for this composition, is the thing to ship. Swapping it is one file
and no code.
